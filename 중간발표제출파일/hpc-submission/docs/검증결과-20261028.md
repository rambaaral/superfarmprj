브라우저 결과는 `browser-check.json`, 화면은 `home.png`, `editor.png`, `application-preview.png`에 포함했다. 시험용 계정·문서·검사 기록은 로컬 검증 볼륨에만 생성되며, 제출 ZIP의 초기 데이터에 포함되지 않는다.

실제 신청 제출부터 전체 심사 단계·회원 탈퇴·백업 복구까지의 종단 간 시험은 이번 패키지 검증에서 수행하지 않았다. PDF 생성은 확인했지만 모든 글꼴·긴 문서·복잡한 표의 출력 품질을 보증하는 검증은 아니다. Pro 플러그인의 외부 라이선스 인증·유료 서비스 호출도 시험하지 않았다.

Debian 제공 ClamAV 1.4.3은 실행 당시 더 최신 버전이 있다는 경고를 표시했지만 정의 갱신 및 실제 검사는 통과했다. 이후 정의 서버의 지원 정책이나 네트워크에 따라 초기 다운로드가 실패할 수 있으며, 이 경우 원래의 다운로드 차단 동작을 유지한다.

## 배포 소스 보존과 로컬 조정

- 운영 사이트 코드는 변경하지 않았다.
- 기본 플러그인부터 활성화한 뒤 Pro 확장판을 활성화하도록 초기화 순서를 정했다.
- WordPress 새 설치와 각 플러그인의 활성화 훅을 실행해 기본 설정을 생성한다.
- 메일은 로컬 테스트 메일함으로만 보내며 운영 SMTP 비밀번호를 사용하지 않는다.
- cPanel 전용 ClamAV 인자만 별도 래퍼에서 제거했다. 검사 결과를 임의로 통과 처리하지 않는다.
- 원본 테마·플러그인 파일과 추가 Docker 호환 파일을 별도 디렉터리에 두었다.

## 파일 무결성

압축파일 옆의 `.sha256`은 ZIP 전체의 SHA-256 값이다. 압축 내부 `SHA256SUMS.txt`는 포함 파일별 SHA-256 값을 기록한다. 압축을 생성할 때 모든 ZIP 항목의 CRC 검사와 실제 `.env` 제외 여부, 테스트 비밀번호가 다른 파일에 들어 있지 않은지 확인한다.
