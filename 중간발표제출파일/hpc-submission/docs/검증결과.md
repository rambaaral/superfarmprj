## 호환 구성과 남은 검증 범위

- KBoard 활성화 후 같은 스키마를 반복 설치하지 않도록 버전 옵션을 기록한다. MariaDB에 없는 MySQL ngram 변수의 초기 탐지는 지원하지 않는 결과로 처리한다. 원본 KBoard 소스는 변경하지 않는다.
- 업무 플러그인의 활성화 훅이 이미 만든 신청 테이블을 초기화 스크립트에서 중복 설치하지 않는다.
- 옛 게시판 자료 정리 참조가 빈 설치에서 실패하지 않도록 `messages`·`forum` 이름의 빈 호환 테이블만 생성한다. 옛 글쓰기 기능이나 운영 기록은 복원하지 않는다.
- ClamAV1.4.3이 권장1.4.6보다 오래됐다는 안내가 있지만 정의 갱신과 실제 검사는 통과했다. Apache에는 로컬 ServerName 기본 안내가 있다. 이를 응용프로그램 오류가 없는 것과 구분한다.
- 위 탈퇴 검증은 CLI의 정리 함수와 합성 JPG/JPEG 경로·게시글을 사용했다. 브라우저 탈퇴 신청부터 재시도까지 전체 흐름, KBoard 실제 첨부·댓글·타인 답글 보존, 운영 백업본 삭제까지 검증한 것은 아니다.
