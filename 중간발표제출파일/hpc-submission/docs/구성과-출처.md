# 구성과 소스 출처

## 데이터 흐름

브라우저 → localhost:8080의 Apache/PHP·WordPress → MariaDB

- 인증 메일: WordPress → 제출용 로컬 메일 어댑터 → Mailpit(localhost:8025).
- 미리보기: 입력값 → PHP 임시 HWPX 생성 → 브라우저 RHWP WebAssembly 렌더링.
- 문서 다운로드: 신청 데이터 → HWPX 작성 → RHWP 서버 변환 → HWP/PDF.
- 첨부: 웹 경로 밖의 전용 볼륨 저장 → 정기 작업의 ClamAV 검사 → 통과 후 권한 확인 다운로드.
- 정기 작업: 컨테이너 cron이 5분마다 WordPress 예약 작업과 HPC 운영 작업 호출.

## 운영 서버와 다른 부분

| 항목 | 제출용 환경 |
|---|---|
| 웹 실행 환경 | 공식 WordPress Apache 이미지의 PHP 8.3. 운영 서버의 PHP 8.2·호스팅 환경과 다름 |
| WordPress 코드 | 서버에서 보고된 7.1.4 설치본 그대로. 공식 배포본 무결성 인증을 의미하지 않음 |
| 데이터베이스 | 새 MariaDB 10.11. 운영 DB 전체 덤프 미포함 |
| 계정 | 받는 사람이 지정한 새 관리자 1명으로 시작 |
| 저장소 | Docker 전용 볼륨. 운영 서버 경로·권한에 의존하지 않음 |
| 메일 | 실제 SMTP 계정 대신 Mailpit으로 포착 |
| 악성코드 검사 | Debian ClamAV. cPanel 전용 인증서 인자를 제거하는 호환 래퍼 사용 |
| HTTPS | localhost HTTP. 인터넷 공개 서비스용 TLS 설정은 별도 |
| 검색·외부 서비스 | 색인 자제 유지. 운영 라이선스·분석 토큰·백업 인증정보는 이전하지 않음 |

## RHWP

- 원본: https://github.com/edwardkim/rhwp
- 포함한 개발 원본 커밋: `1a76570e833917d15817415a53c09ad61ab3203f`.
- `third-party-source/rhwp-source-1a76570.zip`은 해당 커밋의 문서 엔진·바인딩·웹 편집기·SDK·빌드 소스다. 대용량 샘플 문서와 별도 데스크톱·모바일 앱은 제외했다. 전체 저장소는 위 원본 주소에서 받을 수 있다.
- 실제 배포된 웹 모듈은 `site/wp-content/plugins/hpc-feature-lab/vendor/`, 서버 실행 파일은 `private/runtime/`에 포함한다.
- 원본 소스 커밋은 기존 로컬 개발 자료에서 확인했다. 배포 바이너리를 해당 커밋으로 다시 빌드해 바이트 단위 동일성을 검증한 것은 아니다.
- SDK 연동과 입력 항목 연결은 `editor.js`·`editor.php`, 미리보기는 `live-preview.js`, 서버 변환 호출은 `documents.php`에서 확인할 수 있다.
- 원본 라이선스와 런타임 라이브러리·글꼴 고지는 각 배포 디렉터리에 보존했다.

## 패키징 원칙

운영 서버 소스는 수집 당시 상태를 보존하며 Docker 호환 코드는 별도 `docker/` 디렉터리에 두었다. 사이트 설정·계정·신청 데이터는 운영 DB에서 통째로 복사하지 않고 공개 콘텐츠와 필요한 설정만 선택해 새 환경에 등록한다. 소스 전송에 사용한 임시 암호화 파일과 키는 제출물에 포함하지 않는다.
