# Reference assets

Source: user-supplied `www.naas.go.kr.zip`, extracted under `research/naas-reference/www.naas.go.kr/`.

The CSS layout, typography and available images are retained. CSS resource URLs are rewritten to local relative paths; absent assets for unused reference pages use a transparent fallback. No archived JavaScript is executed by the WordPress theme.

Missing UI images were retrieved on 2026-10-19 from the exact `https://www.naas.go.kr/usr/_images/` paths referenced by the archived stylesheets. The list is maintained in `research/fetch-naas-ui-assets.ps1`.

Pretendard license: `Pretendard-LICENSE.txt`, obtained from https://github.com/orioncactus/pretendard/blob/main/LICENSE . This font license is separate from the source site's other assets.

Institutional logos, portraits and certification badges present in the archive are not used in the portal UI. The original building background is used for the requested reference layout. Portal text, navigation targets, calendar and member services are supplied by the existing project.
